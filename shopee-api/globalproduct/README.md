# API List

- [v2.global_product.add_global_item](operations/v2-global-product-add-global-item.json) (POST /api/v2/global_product/add_global_item)：Add global item. Only for China mainland sellers using China Seller Centre(CNSC). More details in https://shopee.cn/cooperate/46/53/926.
- [v2.global_product.add_global_model](operations/v2-global-product-add-global-model.json) (POST /api/v2/global_product/add_global_model)：Add global model. Only for China mainland sellers and Korean sellers.
- [v2.global_product.category_recommend](operations/v2-global-product-category-recommend.json) (GET /api/v2/global_product/category_recommend)：Recommend category by item name. Only for China mainland sellers and Korean sellers.
- [v2.global_product.create_publish_task](operations/v2-global-product-create-publish-task.json) (POST /api/v2/global_product/create_publish_task)：Create publish task for global item. Only for China mainland sellers and Korean sellers.
- [v2.global_product.delete_global_item](operations/v2-global-product-delete-global-item.json) (POST /api/v2/global_product/delete_global_item)：Delete global item. Only for China mainland sellers and Korean sellers.
- [v2.global_product.delete_global_model](operations/v2-global-product-delete-global-model.json) (POST /api/v2/global_product/delete_global_model)：Delete global model. Only for China mainland sellers and Korean sellers.
- [v2.global_product.get_attribute_tree](operations/v2-global-product-get-attribute-tree.json) (GET /api/v2/global_product/get_attribute_tree)：Get the mtsku attribute trees for categories
- [v2.global_product.get_brand_list](operations/v2-global-product-get-brand-list.json) (GET /api/v2/global_product/get_brand_list)：Use this call to get a list of brand. Only for China mainland sellers and Korean sellers.
- [v2.global_product.get_category](operations/v2-global-product-get-category.json) (GET /api/v2/global_product/get_category)：Get global category. Only for China mainland sellers and Korean sellers.
- [v2.global_product.get_global_item_id](operations/v2-global-product-get-global-item-id.json) (GET /api/v2/global_product/get_global_item_id)：Get get_global_item_id by item_id. Only for China mainland sellers and Korean sellers.
- [v2.global_product.get_global_item_info](operations/v2-global-product-get-global-item-info.json) (GET /api/v2/global_product/get_global_item_info)：Get global item info.Only for China mainland sellers and Korean sellers.
- [v2.global_product.get_global_item_limit](operations/v2-global-product-get-global-item-limit.json) (GET /api/v2/global_product/get_global_item_limit)：Get global item upload control.
- [v2.global_product.get_global_item_list](operations/v2-global-product-get-global-item-list.json) (GET /api/v2/global_product/get_global_item_list)：Get global item id list. Only for China mainland sellers and Korean sellers.
- [v2.global_product.get_global_model_list](operations/v2-global-product-get-global-model-list.json) (GET /api/v2/global_product/get_global_model_list)：Get global model list. Only for China mainland sellers and Korean sellers.
- [v2.global_product.get_local_adjustment_rate](operations/v2-global-product-get-local-adjustment-rate.json) (GET /api/v2/global_product/get_local_adjustment_rate)：Retrieves the adjustment rate that converts CB stock price into local-warehouse price for a specific shop.
- [v2.global_product.get_publish_task_result](operations/v2-global-product-get-publish-task-result.json) (GET /api/v2/global_product/get_publish_task_result)：Get publish task result for global item. Only for China mainland sellers and Korean sellers.
- [v2.global_product.get_publishable_shop](operations/v2-global-product-get-publishable-shop.json) (GET /api/v2/global_product/get_publishable_shop)：Get publishable shop list for global item. Only for China mainland sellers and Korean sellers.
- [v2.global_product.get_published_list](operations/v2-global-product-get-published-list.json) (GET /api/v2/global_product/get_published_list)：Get published item list of global item. Only for China mainland sellers and Korean sellers.
- [v2.global_product.get_recommend_attribute](operations/v2-global-product-get-recommend-attribute.json) (GET /api/v2/global_product/get_recommend_attribute)：Get recommend attributes. Only for China mainland sellers and Korean sellers.
- [v2.global_product.get_shop_publishable_status](operations/v2-global-product-get-shop-publishable-status.json) (GET /api/v2/global_product/get_shop_publishable_status)：Get publishable shop list for global item in pages.
- [v2.global_product.get_size_chart_detail](operations/v2-global-product-get-size-chart-detail.json) (GET /api/v2/global_product/get_size_chart_detail)：Get new size chart detail
- [v2.global_product.get_size_chart_list](operations/v2-global-product-get-size-chart-list.json) (GET /api/v2/global_product/get_size_chart_list)：Get size chart list
- [v2.global_product.get_variations](operations/v2-global-product-get-variations.json) (GET /api/v2/global_product/get_variations)：Get the standardized tier variation defined by Shopee, which is currently a three-layer tree structure. The top layer is variations, the second layer is groups, groups are used to divide options, and the third layer is options.
- [v2.global_product.init_tier_variation](operations/v2-global-product-init-tier-variation.json) (POST /api/v2/global_product/init_tier_variation)：Only for China mainland sellers and Korean sellers. If you only define color, it is one tier, if you define color and size, it is two tier. Support two tier structures at most. This API can change no tier to one tier, no tier to two tier, one tier to two tier, two tier to one tier, one tier to no tier, two tier to no tier. Please create variants after an interval of 5 seconds after creating an item, as there may be a delay.
- [v2.global_product.search_global_attribute_value_list](operations/v2-global-product-search-global-attribute-value-list.json) (POST /api/v2/global_product/search_global_attribute_value_list)：this api is for searching attribute value list for attribute with support_search_value flag
- [v2.global_product.set_sync_field](operations/v2-global-product-set-sync-field.json) (POST /api/v2/global_product/set_sync_field)：Set auto sync field. Only for China mainland sellers and Korean sellers.
- [v2.global_product.support_size_chart](operations/v2-global-product-support-size-chart.json) (GET /api/v2/global_product/support_size_chart)：Get category support size chart. Only for China mainland sellers and Korean sellers.
- [v2.global_product.update_global_item](operations/v2-global-product-update-global-item.json) (POST /api/v2/global_product/update_global_item)：Update global item. Only for China mainland sellers and Korean sellers.
- [v2.global_product.update_global_model](operations/v2-global-product-update-global-model.json) (POST /api/v2/global_product/update_global_model)：Update global model. Only for China mainland sellers and Korean sellers.
- [v2.global_product.update_local_adjustment_rate](operations/v2-global-product-update-local-adjustment-rate.json) (POST /api/v2/global_product/update_local_adjustment_rate)：A multiplier that automatically converts your CB stock price into the local-warehouse price. It ensures your local inventory prices reflect regional costs, currency factors, and margin targets.
- [v2.global_product.update_price](operations/v2-global-product-update-price.json) (POST /api/v2/global_product/update_price)：Update global price. Only for China mainland sellers and Korean sellers.
- [v2.global_product.update_size_chart](operations/v2-global-product-update-size-chart.json) (POST /api/v2/global_product/update_size_chart)：Update size chart for global item. Only for China mainland sellers and Korean sellers.
- [v2.global_product.update_stock](operations/v2-global-product-update-stock.json) (POST /api/v2/global_product/update_stock)：Update global stock. Only for China mainland sellers and Korean sellers.
- [v2.global_product.update_tier_variation](operations/v2-global-product-update-tier-variation.json) (POST /api/v2/global_product/update_tier_variation)：Update global product tier variation. Only for China mainland sellers and Korean sellers.This api can only be used without changing the tier structure, you can add options, delete options, and update the option image by this api.
