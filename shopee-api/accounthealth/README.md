# API List

- [v2.account_health.get_late_orders](operations/v2-account-health-get-late-orders.json) (GET /api/v2/account_health/get_late_orders)：Get the Late Orders to take action to avoid order cancellation and penalty points.
- [v2.account_health.get_listings_with_issues](operations/v2-account-health-get-listings-with-issues.json) (GET /api/v2/account_health/get_listings_with_issues)：Get the Problematic Listings to improve the listings to avoid incurring penalty points.
- [v2.account_health.get_metric_source_detail](operations/v2-account-health-get-metric-source-detail.json) (GET /api/v2/account_health/get_metric_source_detail)：Get the Affected Orders / Relevant Listings / Relevant Violations details of metrics.
- [v2.account_health.get_penalty_point_history](operations/v2-account-health-get-penalty-point-history.json) (GET /api/v2/account_health/get_penalty_point_history)：Get the penalty point records generated in the current quarter.
- [v2.account_health.get_punishment_history](operations/v2-account-health-get-punishment-history.json) (GET /api/v2/account_health/get_punishment_history)：Get the punishment records generated in the current quarter.
- [v2.account_health.get_shop_performance](operations/v2-account-health-get-shop-performance.json) (GET /api/v2/account_health/get_shop_performance)：The data metrics of shop performance.
