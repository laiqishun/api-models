# Module List

Choose a business module first, then open its API List to select one operation-level Swagger 2.0 JSON file. Shopee does not provide a Markdown download source; rendered request, response, error, permission, tool, update-log, and example data are retained in the `x-shopee-*` fields of each JSON file.
