# API List

- [v2.merchant.get_merchant_info](operations/v2-merchant-get-merchant-info.json) (GET /api/v2/merchant/get_merchant_info)：Use this call to get information of merchant
- [v2.merchant.get_merchant_prepaid_account_list](operations/v2-merchant-get-merchant-prepaid-account-list.json) (GET /api/v2/merchant/get_merchant_prepaid_account_list)：Use this api to get seller’s courier prepaid account.
- [v2.merchant.get_merchant_warehouse_list](operations/v2-merchant-get-merchant-warehouse-list.json) (POST /api/v2/merchant/get_merchant_warehouse_list)：Get merchant warehouse with page
- [v2.merchant.get_merchant_warehouse_location_list](operations/v2-merchant-get-merchant-warehouse-location-list.json) (GET /api/v2/merchant/get_merchant_warehouse_location_list)：get merchant warehouse location list
- [v2.merchant.get_shop_list_by_merchant](operations/v2-merchant-get-shop-list-by-merchant.json) (GET /api/v2/merchant/get_shop_list_by_merchant)：Use this call to get shop_list bound to merchant_id.
- [v2.merchant.get_warehouse_eligible_shop_list](operations/v2-merchant-get-warehouse-eligible-shop-list.json) (POST /api/v2/merchant/get_warehouse_eligible_shop_list)：Get eligible shop list by warehouse id
