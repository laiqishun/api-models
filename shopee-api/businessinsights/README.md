# API List

- [v2.business_insights.get_marketing_hot_listing](operations/v2-business-insights-get-marketing-hot-listing.json) (POST /api/v2/business_insights/get_marketing_hot_listing)：Returns Business Insights dashboard metrics for shop and product performance, including CTR.

## Modeling notes

The operation JSON retains request and response parameter trees, API-specific and common errors, examples, permissions, API tools, and update logs in `x-shopee-*` fields. Check each operation's `x-shopee-permissions` before treating it as callable.
