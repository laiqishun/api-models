# API List

- [v2.ams.add_all_products_to_open_campaign](operations/v2-ams-add-all-products-to-open-campaign.json) (POST /api/v2/ams/add_all_products_to_open_campaign)：Add all eligible products into the Open Campaign. We will only return the general error that caused the whole task failure, without returning the specific error for each product in the v2.ams.get_open_campaign_batch_task_result API. If you want to get the result for each products, you can use v2.ams.batch_add_products_to_open_campaign by pagination manually, or check the product status by using the GET API after the task progress turn to 100%.
- [v2.ams.batch_add_products_to_open_campaign](operations/v2-ams-batch-add-products-to-open-campaign.json) (POST /api/v2/ams/batch_add_products_to_open_campaign)：Batch add products to the Open Campaign for a given list of product IDs
- [v2.ams.batch_edit_products_open_campaign_setting](operations/v2-ams-batch-edit-products-open-campaign-setting.json) (POST /api/v2/ams/batch_edit_products_open_campaign_setting)：Batch update open campaign settings for a given list of product IDs
- [v2.ams.batch_get_products_suggested_rate](operations/v2-ams-batch-get-products-suggested-rate.json) (GET /api/v2/ams/batch_get_products_suggested_rate)：Fetch suggested rates for a given list of product IDs
- [v2.ams.batch_remove_products_open_campaign_setting](operations/v2-ams-batch-remove-products-open-campaign-setting.json) (POST /api/v2/ams/batch_remove_products_open_campaign_setting)：Batch update products from Open Campaign for a given list of product IDs
- [v2.ams.create_new_targeted_campaign](operations/v2-ams-create-new-targeted-campaign.json) (POST /api/v2/ams/create_new_targeted_campaign)：Create a new campaign with custom product & affiliate selections, and basic info filling.
- [v2.ams.edit_affiliate_list_of_targeted_campaign](operations/v2-ams-edit-affiliate-list-of-targeted-campaign.json) (POST /api/v2/ams/edit_affiliate_list_of_targeted_campaign)：Modify the selected affiliate list in an existing target campaign
- [v2.ams.edit_all_products_open_campaign_setting](operations/v2-ams-edit-all-products-open-campaign-setting.json) (POST /api/v2/ams/edit_all_products_open_campaign_setting)：Update for all products in the Open Campaign. We will only return the general error that caused the whole task failure, without returning the specific error for each product in the v2.ams.get_open_campaign_batch_task_result API. If you want to get the result for each products, you can use v2.ams.batch_edit_products_open_campaign_setting by pagination manually, or check the product status by using the GET API after the task progress turn to 100%.
- [v2.ams.edit_product_list_of_targeted_campaign](operations/v2-ams-edit-product-list-of-targeted-campaign.json) (POST /api/v2/ams/edit_product_list_of_targeted_campaign)：Modify the selected product list in an existing target campaign
- [v2.ams.get_affiliate_performance](operations/v2-ams-get-affiliate-performance.json) (GET /api/v2/ams/get_affiliate_performance)：Retrieve affiliate performance of the shop.
- [v2.ams.get_auto_add_new_product_toggle_status](operations/v2-ams-get-auto-add-new-product-toggle-status.json) (GET /api/v2/ams/get_auto_add_new_product_toggle_status)：Check if auto-add new product is currently enabled
- [v2.ams.get_campaign_key_metrics_performance](operations/v2-ams-get-campaign-key-metrics-performance.json) (GET /api/v2/ams/get_campaign_key_metrics_performance)：Retrieve key metrics for Open and Targeted campaigns
- [v2.ams.get_content_performance](operations/v2-ams-get-content-performance.json) (GET /api/v2/ams/get_content_performance)：Retrieve content performance of the shop
- [v2.ams.get_conversion_report](operations/v2-ams-get-conversion-report.json) (GET /api/v2/ams/get_conversion_report)：Retrieve the shop's conversion report with details about each order, item, affiliate, campaign.You can filter results using one or multiple time ranges, and the final result will be the intersection of these ranges. Due to data volume limitations, the maximum queryable time span is three months, etc.Maximum data can be viewed is 500 pages, please export data for more details.
- [v2.ams.get_managed_affiliate_list](operations/v2-ams-get-managed-affiliate-list.json) (GET /api/v2/ams/get_managed_affiliate_list)：Returns affiliates that are saved to managed affiliate list
- [v2.ams.get_open_campaign_added_product](operations/v2-ams-get-open-campaign-added-product.json) (GET /api/v2/ams/get_open_campaign_added_product)：Retrieve all products currently in the Open Campaign, including campaign status, commission rate, and promotion period
- [v2.ams.get_open_campaign_batch_task_result](operations/v2-ams-get-open-campaign-batch-task-result.json) (GET /api/v2/ams/get_open_campaign_batch_task_result)：Get open campaign batch task result
- [v2.ams.get_open_campaign_not_added_product](operations/v2-ams-get-open-campaign-not-added-product.json) (GET /api/v2/ams/get_open_campaign_not_added_product)：Retrieve eligible products not yet added to the Open Campaign
- [v2.ams.get_open_campaign_performance](operations/v2-ams-get-open-campaign-performance.json) (GET /api/v2/ams/get_open_campaign_performance)：Retrieve all products in the Open Campaign along with performance data
- [v2.ams.get_optimization_suggestion_product](operations/v2-ams-get-optimization-suggestion-product.json) (GET /api/v2/ams/get_optimization_suggestion_product)：Retrieve products with suggestions to improve performance
- [v2.ams.get_performance_data_update_time](operations/v2-ams-get-performance-data-update-time.json) (GET /api/v2/ams/get_performance_data_update_time)：Retrieve the latest date of AMS dashboard data metrics update.
- [v2.ams.get_product_performance](operations/v2-ams-get-product-performance.json) (GET /api/v2/ams/get_product_performance)：Retrieve product performance of the shop.
- [v2.ams.get_recommended_affiliate_list](operations/v2-ams-get-recommended-affiliate-list.json) (GET /api/v2/ams/get_recommended_affiliate_list)：Returns top 200 recommended affiliates that can be added to a campaign
- [v2.ams.get_shop_performance](operations/v2-ams-get-shop-performance.json) (GET /api/v2/ams/get_shop_performance)：Retrieve overall key metrics for all channels or specific channels.
- [v2.ams.get_shop_suggested_rate](operations/v2-ams-get-shop-suggested-rate.json) (GET /api/v2/ams/get_shop_suggested_rate)：Retrieve suggested rates for all eligible products
- [v2.ams.get_targeted_campaign_addable_product_list](operations/v2-ams-get-targeted-campaign-addable-product-list.json) (GET /api/v2/ams/get_targeted_campaign_addable_product_list)：Returns a list of products that can be added to a targeted campaign
- [v2.ams.get_targeted_campaign_list](operations/v2-ams-get-targeted-campaign-list.json) (GET /api/v2/ams/get_targeted_campaign_list)：Retrieve all current targeted campaigns created by the seller
- [v2.ams.get_targeted_campaign_performance](operations/v2-ams-get-targeted-campaign-performance.json) (GET /api/v2/ams/get_targeted_campaign_performance)：Retrieve a list of Targeted Campaigns and their performance data
- [v2.ams.get_targeted_campaign_settings](operations/v2-ams-get-targeted-campaign-settings.json) (GET /api/v2/ams/get_targeted_campaign_settings)：For each campaign, return: campaign basic info (name, status, promotion period, message), selected product list (with product name & ID), selected affiliate list (with affiliate names)
- [v2.ams.get_validation_list](operations/v2-ams-get-validation-list.json) (GET /api/v2/ams/get_validation_list)：Retrieve the seller's AMS validation bill
- [v2.ams.get_validation_report](operations/v2-ams-get-validation-report.json) (GET /api/v2/ams/get_validation_report)：Retrieve detailed information for a specific validation bill
- [v2.ams.query_affiliate_list](operations/v2-ams-query-affiliate-list.json) (GET /api/v2/ams/query_affiliate_list)：Retrieve affiliate information by affiliate id.
- [v2.ams.remove_all_products_open_campaign_setting](operations/v2-ams-remove-all-products-open-campaign-setting.json) (POST /api/v2/ams/remove_all_products_open_campaign_setting)：Remove the entire product list of Open Campaign. We will only return the general error that caused the whole task failure, without returning the specific error for each product in the v2.ams.get_open_campaign_batch_task_result API. If you want to get the result for each products, you can use v2.ams. batch_remove_products_open_campaign_setting by pagination manually, or check the product status by using the GET API after the task progress turn to 100%.
- [v2.ams.terminate_targeted_campaign](operations/v2-ams-terminate-targeted-campaign.json) (POST /api/v2/ams/terminate_targeted_campaign)：Change target campaign status to "terminated" to stop all affiliate promotion activity
- [v2.ams.update_auto_add_new_product_setting](operations/v2-ams-update-auto-add-new-product-setting.json) (POST /api/v2/ams/update_auto_add_new_product_setting)：Change auto-add toggle and default commission rate setting
- [v2.ams.update_basic_info_of_targeted_campaign](operations/v2-ams-update-basic-info-of-targeted-campaign.json) (POST /api/v2/ams/update_basic_info_of_targeted_campaign)：Edit campaign name, promotion period, message, and budget (if the shop is whitelisted) of target campaign
