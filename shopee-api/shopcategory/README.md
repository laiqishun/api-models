# API List

- [v2.shop_category.add_item_list](operations/v2-shop-category-add-item-list.json) (POST /api/v2/shop_category/add_item_list)：Use this call to add items list to certain shop_category
- [v2.shop_category.add_shop_category](operations/v2-shop-category-add-shop-category.json) (POST /api/v2/shop_category/add_shop_category)：Use this call to add a new shop collecion
- [v2.shop_category.delete_item_list](operations/v2-shop-category-delete-item-list.json) (POST /api/v2/shop_category/delete_item_list)：Use this api to delete items from shop category
- [v2.shop_category.delete_shop_category](operations/v2-shop-category-delete-shop-category.json) (POST /api/v2/shop_category/delete_shop_category)：Use this call to delete a existing shop collecion
- [v2.shop_category.get_item_list](operations/v2-shop-category-get-item-list.json) (GET /api/v2/shop_category/get_item_list)：Use this call to get items list of certain shop_category
- [v2.shop_category.get_shop_category_list](operations/v2-shop-category-get-shop-category-list.json) (GET /api/v2/shop_category/get_shop_category_list)：Use this call to get list of shop categories
- [v2.shop_category.update_shop_category](operations/v2-shop-category-update-shop-category.json) (POST /api/v2/shop_category/update_shop_category)：Use this call to update a existing collecion
