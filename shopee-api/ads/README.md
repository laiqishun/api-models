# API List

- [(coming offline soon) v2.ads.create_auto_product_ads](operations/coming-offline-soon-v2-ads-create-auto-product-ads.json) (POST /api/v2/ads/create_auto_product_ads)：Use this API to create Auto Product Ads
- [(coming offline soon) v2.ads.edit_auto_product_ads](operations/coming-offline-soon-v2-ads-edit-auto-product-ads.json) (POST /api/v2/ads/edit_auto_product_ads)：Use this API to edit Auto Product Ads
- [v2.ads.check_create_gms_product_campaign_eligibility](operations/v2-ads-check-create-gms-product-campaign-eligibility.json) (GET /api/v2/ads/check_create_gms_product_campaign_eligibility)：Check the seller's eligibility in creating a GMS campaign
- [v2.ads.create_gms_product_campaign](operations/v2-ads-create-gms-product-campaign.json) (POST /api/v2/ads/create_gms_product_campaign)：Create a GMS campaign
- [v2.ads.create_manual_product_ads](operations/v2-ads-create-manual-product-ads.json) (POST /api/v2/ads/create_manual_product_ads)：Use this API to create Manual Selection Product Ads
- [v2.ads.edit_gms_item_product_campaign](operations/v2-ads-edit-gms-item-product-campaign.json) (POST /api/v2/ads/edit_gms_item_product_campaign)：Add/remove items to/from the GMS Campaign
- [v2.ads.edit_gms_product_campaign](operations/v2-ads-edit-gms-product-campaign.json) (POST /api/v2/ads/edit_gms_product_campaign)：Edit a GMS campaign
- [v2.ads.edit_manual_product_ad_keywords](operations/v2-ads-edit-manual-product-ad-keywords.json) (POST /api/v2/ads/edit_manual_product_ad_keywords)：Use this API to edit Manual Selection Product Ad Keywords
- [v2.ads.edit_manual_product_ads](operations/v2-ads-edit-manual-product-ads.json) (POST /api/v2/ads/edit_manual_product_ads)：Use this API to edit Manual Selection Product Ads
- [v2.ads.get_ads_fácil_shop_rate](operations/v2-ads-get-ads-f-cil-shop-rate.json) (GET /api/v2/ads/get_ads_facil_shop_rate)：Get shop rate for Ads Facil Program
- [v2.ads.get_all_cpc_ads_daily_performance](operations/v2-ads-get-all-cpc-ads-daily-performance.json) (GET /api/v2/ads/get_all_cpc_ads_daily_performance)：Use this API to get Shop level CPC ads multiple-days daily performance.
- [v2.ads.get_all_cpc_ads_hourly_performance](operations/v2-ads-get-all-cpc-ads-hourly-performance.json) (GET /api/v2/ads/get_all_cpc_ads_hourly_performance)：Use this API to get Shop level CPC ads single-date hourly performance.
- [v2.ads.get_create_product_ad_budget_suggestion](operations/v2-ads-get-create-product-ad-budget-suggestion.json) (GET /api/v2/ads/get_create_product_ad_budget_suggestion)：Call this API to get budget suggestion for product ads creation
- [v2.ads.get_gms_campaign_performance](operations/v2-ads-get-gms-campaign-performance.json) (POST /api/v2/ads/get_gms_campaign_performance)：Get GMS Campaign performance
- [v2.ads.get_gms_item_performance](operations/v2-ads-get-gms-item-performance.json) (POST /api/v2/ads/get_gms_item_performance)：Get GMS Item performance 1. The response returned is sorted by item_id 2. Only items with performance will be returned
- [v2.ads.get_product_campaign_daily_performance](operations/v2-ads-get-product-campaign-daily-performance.json) (GET /api/v2/ads/get_product_campaign_daily_performance)：Use this API to get Product level ads multiple-days daily performance.
- [v2.ads.get_product_campaign_hourly_performance](operations/v2-ads-get-product-campaign-hourly-performance.json) (GET /api/v2/ads/get_product_campaign_hourly_performance)：Use this API to get Product level ads single-day hourly performance.
- [v2.ads.get_product_level_campaign_id_list](operations/v2-ads-get-product-level-campaign-id-list.json) (GET /api/v2/ads/get_product_level_campaign_id_list)：Call this API to fetch all the product campaign ids displayed on advertiser platform under a specific Shop
- [v2.ads.get_product_level_campaign_setting_info](operations/v2-ads-get-product-level-campaign-setting-info.json) (GET /api/v2/ads/get_product_level_campaign_setting_info)：Call this API to fetch all the campaign setting info under this Shop.
- [v2.ads.get_product_recommended_roi_target](operations/v2-ads-get-product-recommended-roi-target.json) (GET /api/v2/ads/get_product_recommended_roi_target)：Get Product Recommended ROI Target
- [v2.ads.get_recommended_item_list](operations/v2-ads-get-recommended-item-list.json) (GET /api/v2/ads/get_recommended_item_list)：Use this API to get the list of recommended SKU (Shop level) with the corresponding tag, i.e top search/best selling/best ROI tag.
- [v2.ads.get_recommended_keyword_list](operations/v2-ads-get-recommended-keyword-list.json) (GET /api/v2/ads/get_recommended_keyword_list)：Use this API to get the list of Recommended keywords by item and optionally a search keyword
- [v2.ads.get_shop_toggle_info](operations/v2-ads-get-shop-toggle-info.json) (GET /api/v2/ads/get_shop_toggle_info)：Use this API to get Shop level info - i.e. seller's toggle status is on/off
- [v2.ads.get_total_balance](operations/v2-ads-get-total-balance.json) (GET /api/v2/ads/get_total_balance)：Use this API to return the seller's Real-time total balance of their ads credit including the paid credits and free credits.
- [v2.ads.list_gms_user_deleted_item](operations/v2-ads-list-gms-user-deleted-item.json) (POST /api/v2/ads/list_gms_user_deleted_item)：List GMS items that have been removed from the Campaign by seller
