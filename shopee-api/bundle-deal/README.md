# API List

- [v2.bundle_deal.add_bundle_deal_item](operations/v2-bundle-deal-add-bundle-deal-item.json) (POST /api/v2/bundle_deal/add_bundle_deal_item)：add product to bundle deal
- [v2.bundle_deal.add_bundle_deal](operations/v2-bundle-deal-add-bundle-deal.json) (POST /api/v2/bundle_deal/add_bundle_deal)：create bundle deal. Relevant restrictions refer to FAQ：https://open.shopee.com/faq/254
- [v2.bundle_deal.delete_bundle_deal_item](operations/v2-bundle-deal-delete-bundle-deal-item.json) (POST /api/v2/bundle_deal/delete_bundle_deal_item)：delete product in bundle deal
- [v2.bundle_deal.delete_bundle_deal](operations/v2-bundle-deal-delete-bundle-deal.json) (POST /api/v2/bundle_deal/delete_bundle_deal)：delete bundle deal
- [v2.bundle_deal.end_bundle_deal](operations/v2-bundle-deal-end-bundle-deal.json) (POST /api/v2/bundle_deal/end_bundle_deal)：end bundle deal
- [v2.bundle_deal.get_bundle_deal_item](operations/v2-bundle-deal-get-bundle-deal-item.json) (GET /api/v2/bundle_deal/get_bundle_deal_item)：get bundle deal item
- [v2.bundle_deal.get_bundle_deal_list](operations/v2-bundle-deal-get-bundle-deal-list.json) (GET /api/v2/bundle_deal/get_bundle_deal_list)：get bundle deal list
- [v2.bundle_deal.get_bundle_deal](operations/v2-bundle-deal-get-bundle-deal.json) (GET /api/v2/bundle_deal/get_bundle_deal)：get bundle deal detail
- [v2.bundle_deal.update_bundle_deal_item](operations/v2-bundle-deal-update-bundle-deal-item.json) (POST /api/v2/bundle_deal/update_bundle_deal_item)：update product in bundle deal
- [v2.bundle_deal.update_bundle_deal](operations/v2-bundle-deal-update-bundle-deal.json) (POST /api/v2/bundle_deal/update_bundle_deal)：update bundle deal. Relevant restrictions refer to FAQ：https://open.shopee.com/faq/254
