# API List

- [v2.first_mile.bind_courier_delivery_first_mile_tracking_number](operations/v2-first-mile-bind-courier-delivery-first-mile-tracking-number.json) (POST /api/v2/first_mile/bind_courier_delivery_first_mile_tracking_number)：Use this api to bind first mile tracking number for courier delivery method.
- [v2.first_mile.bind_first_mile_tracking_number](operations/v2-first-mile-bind-first-mile-tracking-number.json) (POST /api/v2/first_mile/bind_first_mile_tracking_number)：Use this api to bind first mile tracking number.
- [v2.first_mile.generate_and_bind_first_mile_tracking_number](operations/v2-first-mile-generate-and-bind-first-mile-tracking-number.json) (POST /api/v2/first_mile/generate_and_bind_first_mile_tracking_number)：Use this api to generate first mile tracking number for courier delivery method.
- [v2.first_mile.generate_first_mile_tracking_number](operations/v2-first-mile-generate-first-mile-tracking-number.json) (POST /api/v2/first_mile/generate_first_mile_tracking_number)：Use this api to generate first mile tracking number.
- [v2.first_mile.get_channel_list](operations/v2-first-mile-get-channel-list.json) (GET /api/v2/first_mile/get_channel_list)：Use this api to get first mile channel list.
- [v2.first_mile.get_courier_delivery_channel_list](operations/v2-first-mile-get-courier-delivery-channel-list.json) (GET /api/v2/first_mile/get_courier_delivery_channel_list)：Use this api to get courier information for courier delivery method.
- [v2.first_mile.get_courier_delivery_detail](operations/v2-first-mile-get-courier-delivery-detail.json) (GET /api/v2/first_mile/get_courier_delivery_detail)：Use this api to get first mile detail for courier delivery method.
- [v2.first_mile.get_courier_delivery_tracking_number_list](operations/v2-first-mile-get-courier-delivery-tracking-number-list.json) (POST /api/v2/first_mile/get_courier_delivery_tracking_number_list)：Use this api to get tracking number for courier delivery method.
- [v2.first_mile.get_courier_delivery_waybill](operations/v2-first-mile-get-courier-delivery-waybill.json) (POST /api/v2/first_mile/get_courier_delivery_waybill)：Use this api to get first mile waybill file for courier delivery method.
- [v2.first_mile.get_detail](operations/v2-first-mile-get-detail.json) (GET /api/v2/first_mile/get_detail)：Use this api to get first mile detail.
- [v2.first_mile.get_tracking_number_list](operations/v2-first-mile-get-tracking-number-list.json) (GET /api/v2/first_mile/get_tracking_number_list)：Use this api to get first mile tracking number list.
- [v2.first_mile.get_transit_warehouse_list](operations/v2-first-mile-get-transit-warehouse-list.json) (GET /api/v2/first_mile/get_transit_warehouse_list)：Use this api to get transit warehouse list which is used for first mile tracking number generation for courier delivery method.
- [v2.first_mile.get_unbind_order_list](operations/v2-first-mile-get-unbind-order-list.json) (GET /api/v2/first_mile/get_unbind_order_list)：Use this api to get unbind order list. It will only return orders unbound to first-mile that were created within the past 6 months.
- [v2.first_mile.get_waybill](operations/v2-first-mile-get-waybill.json) (POST /api/v2/first_mile/get_waybill)：Use this api to get first mile waybill file.
- [v2.first_mile.unbind_first_mile_tracking_number_all](operations/v2-first-mile-unbind-first-mile-tracking-number-all.json) (POST /api/v2/first_mile/unbind_first_mile_tracking_number_all)：Use this api to unbind orders from first mile tracking number or binding ID.
- [v2.first_mile.unbind_first_mile_tracking_number](operations/v2-first-mile-unbind-first-mile-tracking-number.json) (POST /api/v2/first_mile/unbind_first_mile_tracking_number)：Use this api to unbind first mile.
