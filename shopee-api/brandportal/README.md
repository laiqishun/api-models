# API List

- [v2.principal.get_clip_video_performance](operations/v2-principal-get-clip-video-performance.json) (POST /api/v2/principal/get_clip_video_performance)：Queries video clip performance data for the specified videos within the selected time range. Supports request granularity by day, week, month, quarter, year, or customize, and returns both overall summary metrics and video-level detailed metrics.
- [v2.principal.get_content_affiliate_performance](operations/v2-principal-get-content-affiliate-performance.json) (POST /api/v2/principal/get_content_affiliate_performance)：Queries affiliate performance data for the specified content items within the selected time range. Supports request granularity by day, week, month, quarter, year, or customize, and returns both overall summary metrics and content-level detailed metrics with placed-order and confirmed-order views.
- [v2.principal.get_principal_affiliate_performance](operations/v2-principal-get-principal-affiliate-performance.json) (POST /api/v2/principal/get_principal_affiliate_performance)：Queries affiliate performance data for the specified principal within the selected time range. Supports request granularity by day, week, month, quarter, year, or customize, and returns both overall summary metrics and region-level detailed metrics with placed-order and confirmed-order views.
- [v2.principal.get_principal_livestream_performance](operations/v2-principal-get-principal-livestream-performance.json) (POST /api/v2/principal/get_principal_livestream_performance)：Queries livestream performance data for the specified principal within the selected time range. Supports request granularity by day, week, month, quarter, year, or customize, and returns both overall summary metrics and region-level detailed metrics.
- [v2.principal.get_principal_sales_performance_detail](operations/v2-principal-get-principal-sales-performance-detail.json) (POST /api/v2/principal/get_principal_sales_performance_detail)：Queries the business performance data aggregated at principal level for the specified regions within the selected time range. Supports request granularity by day, week, month, quarter, year, or customize, and returns both overall summary metrics and region-level detailed metrics.
- [v2.principal.get_principal_video_performance](operations/v2-principal-get-principal-video-performance.json) (POST /api/v2/principal/get_principal_video_performance)：Queries video performance data for the specified principal within the selected time range. Supports request granularity by day, week, month, quarter, year, or customize, and returns both overall summary metrics and region-level detailed metrics.
- [v2.principal.get_session_livestream_performance](operations/v2-principal-get-session-livestream-performance.json) (POST /api/v2/principal/get_session_livestream_performance)：Queries livestream session performance data for the specified sessions within the selected time range. Supports request granularity by day, week, month, quarter, year, or customize, and returns both overall summary metrics and session-level detailed metrics.
- [v2.principal.get_shop_affiliate_performance](operations/v2-principal-get-shop-affiliate-performance.json) (POST /api/v2/principal/get_shop_affiliate_performance)：Queries affiliate performance data for the specified shops within the selected time range. Supports request granularity by day, week, month, quarter, year, or customize, and returns both overall summary metrics and shop-level detailed metrics with placed-order and confirmed-order views.
- [v2.principal.get_shop_livestream_performance](operations/v2-principal-get-shop-livestream-performance.json) (POST /api/v2/principal/get_shop_livestream_performance)：Queries livestream performance data for the specified shops within the selected time range. Supports request granularity by day, week, month, quarter, year, or customize, and returns both overall summary metrics and shop-level detailed metrics.
- [v2.principal.get_shop_sales_performance_detail](operations/v2-principal-get-shop-sales-performance-detail.json) (POST /api/v2/principal/get_shop_sales_performance_detail)：Queries the business performance data of stores under the specified entity within the selected time range. Supports request granularity by day, week, month, quarter, year, or customize, and returns both overall summary metrics and store-level detailed metrics.
- [v2.principal.get_shop_video_performance](operations/v2-principal-get-shop-video-performance.json) (POST /api/v2/principal/get_shop_video_performance)：Queries video performance data for the specified shops within the selected time range. Supports request granularity by day, week, month, quarter, year, or customize, and returns both overall summary metrics and shop-level detailed metrics.
