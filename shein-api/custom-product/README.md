# API List

Official category: [定制商品 (3000010)](https://open.sheincorp.com/documents/apidoc/3000010). 5 records. Official IDs, applicable modes, and update times remain in the [manifest](../manifest.md) and each JSON file.

- [createProductionTemplateTask](operations/createProductionTemplateTask.json) (POST /open-api/ccst/v1/composite/task)：Create production template task（创建⽣产模板任务）
- [getCustomizedData](operations/getCustomizedData.json) (GET /open-api/ccst/v1/custom-infos)：Get customized data（获取定制数据）
- [getTemplateData](operations/getTemplateData.json) (GET /open-api/ccst/v1/custom-info/templates)：Get template data（获取模版数据）
- [queryAddToCartStructureInformation](operations/queryAddToCartStructureInformation.json) (POST /open-api/ccst/v1/custom-info/queryAddCartInfo)：Query Add-to-Cart Structure Information（查询加车结构信息）
- [queryTaskResults](operations/queryTaskResults.json) (GET /open-api/ccst/v1/composite/queryTask)：Query task results（查询任务结果）
