# API List

Official category: [认证仓 (3000001)](https://open.sheincorp.com/documents/apidoc/3000001). 4 records. Official IDs, applicable modes, and update times remain in the [manifest](../manifest.md) and each JSON file.

- [callbackOutboundOrderCreationResult](operations/callbackOutboundOrderCreationResult.json) (POST /open-api/order/openapi/auth/order/outbound-result)：Callback outbound order creation result（认证仓调用-回调出库单创建结果接口）
- [receiveCertifiedWarehouseChannelChange](operations/receiveCertifiedWarehouseChannelChange.json) (POST /open-api/lsps-java/auth/entity-change)：Authentication Warehouse Call-Receive Authentication Warehouse Service Provider Warehouse Channel Change Interface（认证仓调用-接收认证仓服务商仓库渠道变更接口）
- [uploadLogisticsWaybill](operations/uploadLogisticsWaybill.json) (POST /open-api/order/openapi/auth/order/express-upload)：Upload logistics waybill（认证仓调用-上传物流运单接口）
- [voidOutboundOrder](operations/voidOutboundOrder.json) (POST /open-api/order/openapi/auth/order/outbound-cancel)：Void outbound order（认证仓调用-作废出库单接口）
