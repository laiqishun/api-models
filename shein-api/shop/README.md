# API List

Official category: [店铺 (3000007)](https://open.sheincorp.com/documents/apidoc/3000007). 3 records. Official IDs, applicable modes, and update times remain in the [manifest](../manifest.md) and each JSON file.

- [getAnnouncementDetails](operations/getAnnouncementDetails.json) (POST /open-api/ssls/announcement/get-anno-detail)：Get announcement details（获取公告详情）
- [queryAnnouncementList](operations/queryAnnouncementList.json) (POST /open-api/ssls/announcement/get-anno-list)：Query announcement list（查询公告列表）
- [queryStoreInformation](operations/queryStoreInformation.json) (POST /open-api/openapi-business-backend/query-store-info)：Query store information（查询店铺信息）
