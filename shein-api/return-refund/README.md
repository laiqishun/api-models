# API List

Official category: [退货退款 (2000004)](https://open.sheincorp.com/documents/apidoc/2000004). 3 records. Official IDs, applicable modes, and update times remain in the [manifest](../manifest.md) and each JSON file.

- [queryReturnOrderDetails](operations/queryReturnOrderDetails.json) (POST /open-api/return-order/details)：Query return order details（退货单详情查询）
- [queryReturnOrderList](operations/queryReturnOrderList.json) (POST /open-api/return-order/list)：Query return order list（查询退货单列表）
- [receiveReturnOrder](operations/receiveReturnOrder.json) (POST /open-api/return-order/sign-return-order)：Receive return order（退货单签收）
