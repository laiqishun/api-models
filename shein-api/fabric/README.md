# API List

Official category: [面料 (1000005)](https://open.sheincorp.com/documents/apidoc/1000005). 6 records. Official IDs, applicable modes, and update times remain in the [manifest](../manifest.md) and each JSON file.

- [initiateQuickSupplyTask](operations/initiateQuickSupplyTask.json) (POST /open-api/material/mesCreateAddSupp)：Initiate quick supply task（发起快速加供任务）
- [supplierInventoryInboundSynchronization](operations/supplierInventoryInboundSynchronization.json) (POST /open-api/material/in-inventory)：Supplier inventory-inbound synchronization interface（供应商库存-入库同步接口）
- [supplierInventoryInventorySynchronization](operations/supplierInventoryInventorySynchronization.json) (POST /open-api/material/sync-inventory)：Supplier Inventory - Inventory Synchronization Interface（供应商库存-库存同步接口）
- [supplierInventoryOutboundSynchronization](operations/supplierInventoryOutboundSynchronization.json) (POST /open-api/material/out-inventory)：Supplier inventory-outbound synchronization interface（供应商库存-出库同步接口）
- [supplierOrderShippingInformation](operations/supplierOrderShippingInformation.json) (POST /open-api/material/sales-order-deliver-info)：Supplier Order - Shipping Information（供应商订单-发货信息）
- [supplierQualityInspectionClothInspectionReport](operations/supplierQualityInspectionClothInspectionReport.json) (POST /open-api/material/receive-cloth-report)：Supplier Quality Inspection - Cloth Inspection Report（供应商质检-验布报告）
