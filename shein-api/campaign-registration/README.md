# API List

Official category: [营销活动报名 (3000009)](https://open.sheincorp.com/documents/apidoc/3000009). 6 records. Official IDs, applicable modes, and update times remain in the [manifest](../manifest.md) and each JSON file.

- [cancelCampaignRegistration](operations/cancelCampaignRegistration.json) (POST /open-api/campaigns/cancel-registration)：Cancel campaign registration（取消活动报名）
- [queryAvailableCampaignList](operations/queryAvailableCampaignList.json) (POST /open-api/campaigns/campaign-list)：Query Available Campaign List（查询可报活动列表）
- [queryCampaignDetails](operations/queryCampaignDetails.json) (POST /open-api/campaigns/campaign-detail)：Query campaign details（查询活动详情）
- [queryCampaignRegistrationRecordList](operations/queryCampaignRegistrationRecordList.json) (POST /open-api/campaigns/registration-records)：Query campaign registration record list（查询活动报名记录列表）
- [queryListOfProductsEligibleForCampaignRegistration](operations/queryListOfProductsEligibleForCampaignRegistration.json) (POST /open-api/campaigns/registrable-product-list)：Query list of products eligible for campaign registration（查询活动可报商品列表）
- [signUpForCampaign](operations/signUpForCampaign.json) (POST /open-api/campaigns/register-campaign)：Sign up for campaign（报名活动）
