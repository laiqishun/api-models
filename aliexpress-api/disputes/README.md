# API List

Official category ID: 20898. Applicable permissions and seller modes must be checked in the current application. [Manifest](../manifest.md).

- [aliexpressIssueImageUpload](operations/aliexpressIssueImageUpload.json) (GET/POST `/sync?method=aliexpress.issue.image.upload`)：卖家上传纠纷证据图片 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=20898&path=aliexpress.issue.image.upload&methodType=GET%2FPOST)
- [aliexpressIssueSolutionAgree](operations/aliexpressIssueSolutionAgree.json) (GET/POST `/sync?method=aliexpress.issue.solution.agree`)：卖家同意普通纠纷方案 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=20898&path=aliexpress.issue.solution.agree&methodType=GET%2FPOST)
- [aliexpressIssueSolutionSave](operations/aliexpressIssueSolutionSave.json) (GET/POST `/sync?method=aliexpress.issue.solution.save`)：卖家新增(拒绝某个买家方案)or修改方案 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=20898&path=aliexpress.issue.solution.save&methodType=GET%2FPOST)
- [aliexpressIssueIssuelistGet](operations/aliexpressIssueIssuelistGet.json) (GET/POST `/sync?method=aliexpress.issue.issuelist.get`)：获取纠纷列表 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=20898&path=aliexpress.issue.issuelist.get&methodType=GET%2FPOST)
- [aliexpressIssueDetailGet](operations/aliexpressIssueDetailGet.json) (GET/POST `/sync?method=aliexpress.issue.detail.get`)：获取纠纷详情 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=20898&path=aliexpress.issue.detail.get&methodType=GET%2FPOST)
