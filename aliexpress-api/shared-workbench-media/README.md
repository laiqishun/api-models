# API List

Official category ID: 21402. Applicable permissions and seller modes must be checked in the current application. [Manifest](../manifest.md).

- [globalMediacenterImageUpload](operations/globalMediacenterImageUpload.json) (post `/sync?method=global.mediacenter.image.upload`)：上传图片到媒体中心 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=21402&path=global.mediacenter.image.upload&methodType=POST)

- [globalMediacenterImageListpage](operations/globalMediacenterImageListpage.json) (get `/sync?method=global.mediacenter.image.listpage`)：分页查询文件夹下图片信息 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=21402&path=global.mediacenter.image.listpage&methodType=GET)
- [globalMediacenterVideoDelete](operations/globalMediacenterVideoDelete.json) (post `/sync?method=global.mediacenter.video.delete`)：删除单个视频 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=21402&path=global.mediacenter.video.delete&methodType=POST)
- [globalMediacenterImageDelete](operations/globalMediacenterImageDelete.json) (post `/sync?method=global.mediacenter.image.delete`)：删除媒体中心的图片 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=21402&path=global.mediacenter.image.delete&methodType=POST)

- [globalMediacenterVideoGetbystoragename](operations/globalMediacenterVideoGetbystoragename.json) (get `/sync?method=global.mediacenter.video.getbystoragename`)：查询单个视频信息 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=21402&path=global.mediacenter.video.getbystoragename&methodType=GET)
- [globalMediacenterBaseinfoGet](operations/globalMediacenterBaseinfoGet.json) (get `/sync?method=global.mediacenter.baseinfo.get`)：查询媒体中心容量信息 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=21402&path=global.mediacenter.baseinfo.get&methodType=GET)
- [globalMediacenterFolderQuery](operations/globalMediacenterFolderQuery.json) (get `/sync?method=global.mediacenter.folder.query`)：查询文件夹信息 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=21402&path=global.mediacenter.folder.query&methodType=GET)
- [globalMediacenterImageListbypath](operations/globalMediacenterImageListbypath.json) (get `/sync?method=global.mediacenter.image.listbypath`)：根据path查询图片信息 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=21402&path=global.mediacenter.image.listbypath&methodType=GET)
- [globalMediacenterVideoChannelTransfer](operations/globalMediacenterVideoChannelTransfer.json) (post `/sync?method=global.mediacenter.video.channel.transfer`)：视频转存其他渠道 [Official](https://open.aliexpress.com/doc/api.htm?#/api?cid=21402&path=global.mediacenter.video.channel.transfer&methodType=POST)
