# API List

These four APIs are referenced by the official POP integration solution and have readable detail records, but are absent from the current public category list. Their permission, lifecycle and live availability require platform confirmation. They are supplemental to the 496 catalog records.

- [aliexpressSolutionBatchProductPriceUpdate](operations/aliexpressSolutionBatchProductPriceUpdate.json) (GET/POST `/sync?method=aliexpress.solution.batch.product.price.update`)：Batch product price update [Official detail](https://open.aliexpress.com/handler/share/apidoc/getApi.json?path=aliexpress.solution.batch.product.price.update)
- [aliexpressSolutionProductEdit](operations/aliexpressSolutionProductEdit.json) (GET/POST `/sync?method=aliexpress.solution.product.edit`)：Edit Product API [Official detail](https://open.aliexpress.com/handler/share/apidoc/getApi.json?path=aliexpress.solution.product.edit)
- [aliexpressSolutionProductPost](operations/aliexpressSolutionProductPost.json) (GET/POST `/sync?method=aliexpress.solution.product.post`)：Product posting API [Official detail](https://open.aliexpress.com/handler/share/apidoc/getApi.json?path=aliexpress.solution.product.post)
- [aliexpressCategoryRedefiningGetchildrenpostcategorybyid](operations/aliexpressCategoryRedefiningGetchildrenpostcategorybyid.json) (GET/POST `/sync?method=aliexpress.category.redefining.getchildrenpostcategorybyid`)：获取指定类目下子类目信息 [Official detail](https://open.aliexpress.com/handler/share/apidoc/getApi.json?path=aliexpress.category.redefining.getchildrenpostcategorybyid)
