# API List
- [SBCreateAdvertisingDeal](operations/SBCreateAdvertisingDeal.json) (POST /adsApi/v1/create/advertisingDeals/sb)：Create advertisingDeal

- [SBDeleteAdvertisingDeal](operations/SBDeleteAdvertisingDeal.json) (POST /adsApi/v1/delete/advertisingDeals/sb)：Delete advertisingDeal
- [SBDeleteAdvertisingDealTarget](operations/SBDeleteAdvertisingDealTarget.json) (POST /adsApi/v1/delete/advertisingDealTargets/sb)：Delete advertisingDealTarget
- [SBQueryAdvertisingDeal](operations/SBQueryAdvertisingDeal.json) (POST /adsApi/v1/query/advertisingDeals/sb)：Query advertisingDeal
- [SBQueryAdvertisingDealTarget](operations/SBQueryAdvertisingDealTarget.json) (POST /adsApi/v1/query/advertisingDealTargets/sb)：Query advertisingDealTarget
- [SBUpdateAdvertisingDeal](operations/SBUpdateAdvertisingDeal.json) (POST /adsApi/v1/update/advertisingDeals/sb)：Update advertisingDeal
