# API Groups

Related resources under the same product domain are grouped into one directory. Open a group README, pick one operation from the API list, then load that JSON.

- [Ad Associations](ad-associations/README.md)：Amazon Ads API group for Ad Associations operations.
- [Ad Extensions](ad-extensions/README.md)：Amazon Ads API group for Ad Extensions operations.
- [Ad Groups](ad-groups/README.md)：Amazon Ads API group for Ad Groups operations.
- [Ads](ads/README.md)：Amazon Ads API group for Ads operations.
- [Advertising Deals](advertising-deals/README.md)：Amazon Ads Sponsored Brands advertising deals and deal targets.
- [Brand Stores](brand-stores/README.md)：Amazon Ads Brand Stores: store content, pages, editions, and edition publish versions.
- [Campaign Forecasts](campaign-forecasts/README.md)：Amazon Ads API group for Campaign Forecasts operations.
- [Campaigns](campaigns/README.md)：Amazon Ads API group for Campaigns operations.
- [Commitments](commitments/README.md)：Amazon Ads DSP commitments and commitment spend queries.
- [Geo Locations](geo-locations/README.md)：Amazon Ads API group for Geo Locations operations.
- [Location Indexes](location-indexes/README.md)：Amazon Ads API group for Location Indexes operations.
- [Profiles](profiles/README.md)：Profiles represent an advertiser and their account's marketplace, and are used in all subsequent API calls via a management scope, `Amazon-Advertising-API-Scope`.
- [Recommendations](recommendations/README.md)：Amazon Ads Sponsored Brands recommendations and recommendation types.
- [Reporting](reporting/README.md)：Amazon Ads API group for asynchronous reporting operations.
- [SB Keyword Pricing](sb-keyword-pricing/README.md)：Amazon Ads Sponsored Brands branded-keyword pricing, reserved-target pricing, and keyword reservation validation.
- [Targets](targets/README.md)：Amazon Ads API group for Targets operations.
