同一业务域下的相关资源接口。先按用户意图从下方列表选择唯一 operation，再打开对应 JSON。

# API List
- [ListBrandStoreEdition](operations/ListBrandStoreEdition.json) (GET /adsApi/v1/brandStoreEditions)：List brand store editions
- [QueryBrandStore](operations/QueryBrandStore.json) (POST /adsApi/v1/query/brandStores)：Query brand store content
- [QueryBrandStoreEditionPublishVersion](operations/QueryBrandStoreEditionPublishVersion.json) (POST /adsApi/v1/query/brandStoreEditionPublishVersions)：Query store edition publish versions
- [QueryBrandStorePage](operations/QueryBrandStorePage.json) (POST /adsApi/v1/query/brandStorePages)：Retrieve brand store page content
- [UpdateBrandStoreEditionPublishVersion](operations/UpdateBrandStoreEditionPublishVersion.json) (POST /adsApi/v1/update/brandStoreEditionPublishVersions)：Update store edition publish versions
