# API List

- [Add Showcase Products](operations/add-showcase-products-202405.json) (POST /affiliate_creator/202405/showcases/products/add)：This API adds the products to the creator's showcase. The platform will return the add status of the products, and error code and error message if the deletion fails.
- [Creator Generate General Link](operations/creator-generate-general-link-202505.json) (POST /affiliate_creator/202505/affiliate_sharing_links/general_publishers/generate_batch)：You can use this API to generate material sharing links for your publishers. After that, you can encapsulate the sharing link with additional information like publisher ID. Right now, the material type must be `PRODUCT`. Please ensure that the material is included in the campaign by using [Generate Multi Affiliate Partner Campaign Product Links].
- [Creator Generate Publisher Link](operations/creator-generate-publisher-link-202504.json) (POST /affiliate_creator/202504/affiliate_sharing_links/publisher/{publisher_id}/generate_batch)：You can use this API to generate material sharing links for a specific publisher. After that, you can share the link with the publisher. Right now, the material type must be `PRODUCT`. Please ensure that the material is included in the campaign by using [Generate Multi Affiliate Partner Campaign Product Links](generate-multi-affiliate-partner-campaign-product-links).
- [Creator Search Affiliate Trace Orders](operations/creator-search-affiliate-trace-orders-202505.json) (POST /affiliate_creator/202505/orders/trace/search)：This API allows the partner to retrieve a list of affiliate orders generated by a creator, returning the order ID and the product ID. Using this, the partner can track their affiliate-conversions on behalf of a creator, using the order ID.
- [Creator Search Open Collaboration Product](operations/creator-search-open-collaboration-product-202405.json) (POST /affiliate_creator/202405/open_collaborations/products/search)：This API is used to search the information of products with open collaboration by category, commission rate, and keywords. It will return all products on the TikTok Shop Affiliate Product Marketplace that are in an open collaboration. Creators can only search for open collaboration within the regions they are registered in the affiliate.
- [Creator Search Sample Application Fulfillments](operations/creator-search-sample-application-fulfillments-202409.json) (POST /affiliate_creator/202409/sample_applications/fulfillments/search)：You, the creator, can use this API to query the fulfillment status for the received sample applications.
- [Get Creator Applicable Sample Label](operations/get-creator-applicable-sample-label-202412.json) (GET /affiliate_creator/202412/samples/labels)：Check if a creator can apply for a sample of a specific product.
- [Get Creator Profile](operations/get-creator-profile-202508.json) (GET /affiliate_creator/202508/profiles)：This API gets the creator profile information.
- [Get Creator Sample Application Detail](operations/get-creator-sample-application-detail-202412.json) (POST /affiliate_creator/202412/sample_applications/single_query)：Get the sample detail of specified sample application.
- [Get Open Collaboration Product List By Product Ids](operations/get-open-collaboration-product-list-by-product-ids-202509.json) (POST /affiliate_creator/202509/open_collaborations/products)：Get Product OpenCollaboration Product List By Product Ids
- [Get Shop Products](operations/get-shop-products-202509.json) (GET /affiliate_creator/202509/shop_products)：Developer can utilize this API to search and retrieve products information of shop which is bound by a specific creator with specific keywords.
- [Get Shoppable Video Precheck Result](operations/get-shoppable-video-precheck-result-202601.json) (GET /affiliate_creator/202601/videos/precheck_tasks/{task_id})：Use this API to get video pre-check result
- [Get Shoppable Video Status](operations/get-shoppable-video-status-202509.json) (GET /affiliate_creator/202509/videos/{video_id}/status)：Use this API to get shoppable video posting results.
- [Get Showcase Products](operations/get-showcase-products-202405.json) (GET /affiliate_creator/202405/showcases/products)：This API lists the products in the creator's showcase, paginated by specified page size and iterated through pages by page token for up to 2000 products in the showcase. This API is generally used when a creator would like to view the products in the showcase. The platform will return the product details in the showcase, as well as the products in the livebag if the creator is live streaming.
- [Get Toko Product Mappers](operations/get-toko-product-mappers-202606.json) (GET /affiliate_creator/202606/toko_product_mappers)：This API for provide TikTok Shop format product id information by using Tokopedia format product id
- [Post Shoppable Photos](operations/post-shoppable-photos-202607.json) (POST /affiliate_creator/202607/photos)：Use this API to post the shoppable photos with uris and metadata.
- [Post Shoppable Video](operations/post-shoppable-video-202607.json) (POST /affiliate_creator/202607/videos)：Use this API to post the shoppable video.
- [Precheck Video Content](operations/precheck-video-content-202511.json) (POST /affiliate_creator/202511/videos/precheck_task)：Use this API to pre-check if there's any violation in the video and the shoppable content anchor
- [Remove Showcase Products](operations/remove-showcase-products-202409.json) (DELETE /affiliate_creator/202409/showcases/products)：This API removes the products in the creator's showcase. The platform will return error code and error message if the deletion fails.
- [Search Creator Affiliate Orders](operations/search-creator-affiliate-orders-202410.json) (POST /affiliate_creator/202410/orders/search)：Search Creator Affiliate Orders This API allows the partner to retrieve a list of affiliate orders generated by a creator, returning the order ID and the product ID. Using this, the partner can track their affiliate-conversions on behalf of a creator, using the order ID.
- [Search Creator Sample Applications](operations/search-creator-sample-applications-202412.json) (POST /affiliate_creator/202412/sample_applications/search)：Get sample application list of creator.
- [Search Creator Target Collaborations](operations/search-creator-target-collaborations-202405.json) (POST /affiliate_creator/202405/target_collaborations/search)：This API is used to search for creator's target collaborations and the products within these target collaborations.
- [Search Music](operations/search-music-202602.json) (GET /affiliate_creator/202602/music/search)：Use this api to get music info.
- [Toko Product Mapper V2](operations/toko-product-mapper-v2-202607.json) (POST /affiliate_creator/202607/map_toko_product)：This API for provide TikTok Shop format product id information by using Tokopedia format product id
- [Top Showcase Products](operations/top-showcase-products-202409.json) (POST /affiliate_creator/202409/showcases/products/top)：Use this API to move products to the top in a creator's showcase. The platform will return the error code and error message if the pinning operation fails.
- [Upload Shoppable Photo File](operations/upload-shoppable-photo-file-202511.json) (POST /affiliate_creator/202511/photos/photo_files)：Use this API to upload the photos before photo posting. It returns the photo_file_uri for each uploaded image
- [Upload Shoppable Video File](operations/upload-shoppable-video-file-202505.json) (POST /affiliate_creator/202505/videos/video_files)：Use this API to upload the video before posting to TikTok
