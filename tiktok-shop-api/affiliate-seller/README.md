# API List

- [Cancel Target Collaboration Conflicts](operations/cancel-target-collaboration-conflicts-202605.json) (POST /affiliate_seller/202605/target_collaborations/conflicts/resolve)：Execute resolution actions on resolvable conflict items within the scope of seller authorization.
- [Check Target Collaboration Conflicts](operations/check-target-collaboration-conflicts-202605.json) (POST /affiliate_seller/202605/target_collaborations/conflicts/check)：Retrieve conflicting target collaborations for the product and determine if they can be terminated
- [Create Compass Offline Export Task](operations/create-compass-offline-export-task-202603.json) (POST /affiliate_seller/202603/compass/offline_task)：Create an asynchronous offline export task for the specified doc_type and plan_type within a given time window. Returns a task_id for subsequent status query and file download.
- [Create Conversation with creator](operations/create-conversation-with-creator-202508.json) (POST /affiliate_seller/202508/conversations)：Get the existing conversation or create a new conversation with the specified TikTok creator for later communication.
- [Create Open Collaboration](operations/create-open-collaboration-202412.json) (POST /affiliate_seller/202412/open_collaborations)：This API allows the seller to create an open collaboration. You create an open collaboration by selecting products and setting a commission rate.
- [Create Target Collaboration](operations/create-target-collaboration-202508.json) (POST /affiliate_seller/202508/target_collaborations)：This API is used to create a target collaboration. A target collaboration is a collaboration between a seller selected set of products (including a commission payout) and a set of creators the seller has added (invited) to the collaboration. Target collaborations are private and not visible in the Creator Marketplace to all creators; they are only visible to those that have been added to the collaboration.
- [Download Compass Task File](operations/download-compass-task-file-202603.json) (GET /affiliate_seller/202603/compass/offline_tasks/{task_id}/file)：Download the result file of a completed export task by taskId. Requires ownership validation; returns file.
- [Edit Open Collaboration Sample Rule](operations/edit-open-collaboration-sample-rule-202410.json) (POST /affiliate_seller/202410/open_collaborations/sample_rules)：Use this API to manage sample rules in open collaborations, like valid time periods, or thresholds for creators to request samples. You can create, update, or deactivate rules.
- [Edit Open Collaboration Settings](operations/edit-open-collaboration-settings-202405.json) (POST /affiliate_seller/202405/open_collaboration_settings)：This API is used to edit a Seller's open collaboration settings. It allows you to enroll your existing product catalog and all future products into an open collaboration plan. It also allows you to turn this setting off at any point. By default, this option is turned off for all Sellers.
- [Generate Affiliate Product Promotion Link](operations/generate-affiliate-product-promotion-link-202405.json) (POST /affiliate_seller/202405/products/{product_id}/promotion_link/generate)：The user of this API is a partner developer, on behalf of Sellers. This API is used to generate affiliate exclusive product link based on all open collaboration products available within the TikTok Shop Affiliate Product Marketplace. This API generates a link, at the product ID level (which belongs to a Seller). This link, can be distributed to creators, by the partner developer(the user of this API). The creator adds this product to the creators' showcase through this url. This link, represents an affiliate partner's ability to bring higher matchmaking effectiveness on behalf of a seller. If a creator does indeed add the product to showcase through this link, then the downstream consumer purchases will be able to be attributed to this partner due to the link generation capabilities.
- [Generate Target Collaboration Link](operations/generate-target-collaboration-link-202509.json) (POST /affiliate_seller/202509/target_collaboration/{target_collaboration_id}/link)：Generate a Target Collaboration Link that the seller can share with the creator. This link directs the creator to a guided flow to review details and formally accept the target collaboration
- [Get Compass Task List](operations/get-compass-task-list-202603.json) (GET /affiliate_seller/202603/compass/offline_tasks)：Retrieve the list of export tasks created via Open API for the authorized seller (last 7 days). Supports pagination and returns task status, file_name and timestamps.
- [Get Conversation List](operations/get-conversation-list-202412.json) (GET /affiliate_seller/202412/conversations)：Get User's Conversation list.
- [Get Inbox Category Counts](operations/get-inbox-category-counts-202608.json) (GET /affiliate_seller/202608/conversations/group_counts)：Query the number of sessions grouped by status such as read, unread, starred and archived.
- [Get Latest Unread Messages](operations/get-latest-unread-messages-202412.json) (GET /affiliate_seller/202412/conversations/messages/list/newest)：Get the unread messages from the last minute. You are recommended to use the Webhook, New Message Listener, for the message notification.
- [Get Marketplace Creator Performance](operations/get-marketplace-creator-performance-202608.json) (GET /affiliate_seller/202608/marketplace_creators/{creator_user_id})：Get the Creator Affiliate's Marketplace information and performance metrics in the last 30 days.
- [Get Message in the Conversation](operations/get-message-in-the-conversation-202412.json) (GET /affiliate_seller/202412/conversation/{conversation_id}/messages)：Get chat history in one conversation.
- [Get Open Collaboration Creator Content Detail](operations/get-open-collaboration-creator-content-detail-202508.json) (GET /affiliate_seller/202508/open_collaborations/creator_content_details)：This API allows the seller to get the creator content details of specified open collaboration.
- [Get Open Collaboration Sample Rules](operations/get-open-collaboration-sample-rules-202410.json) (GET /affiliate_seller/202410/open_collaborations/sample_rules)：Use this API to get the status and the details of the sample rules for products under an open collaboration. With this API, you can efficiently review the sample distribution criteria for products within the open collaboration context.
- [Get Open Collaboration Settings](operations/get-open-collaboration-settings-202409.json) (GET /affiliate_seller/202409/open_collaboration_settings)：Get the open collaboration settings, including auto add settings.
- [Get Seller Search Creator Marketplace Advanced Filters](operations/get-seller-search-creator-marketplace-advanced-filters-202608.json) (POST /affiliate_seller/202608/marketplace_creators/search/filter)：This API allows you to obtain the advanced filters available in Seller Search Creator Marketplace. Because we are constantly releasing new filters which are specific to each country or region, this API serves as a way for developers to retrieve the latest available search filters.
- [Get Weekly Creator Outreach Quota](operations/get-weekly-creator-outreach-quota-202607.json) (GET /affiliate_seller/202607/creator_outreach/quota)：Query the weekly outreach invitation quota for a shop. It returns the current GMV tier, maximum reachable creator follower count corresponding to the tier, consumed quota, remaining quota and other related information.
- [Get Weekly Creator Outreach Records](operations/get-weekly-creator-outreach-records-202608.json) (POST /affiliate_seller/202608/creator_outreach/records/query)：Query weekly detailed outreach‑invitation records for a specified seller, including whether IM messages/invitations were sent to a unconnected creator, and whether the creator added products or replied to IM messages.
- [Mark Conversation Read](operations/mark-conversation-read-202412.json) (POST /affiliate_seller/202412/conversatons/read)：Mark the messages in the specified conversations to be read.
- [Query Creator Promotion Details in Target Collaboration](operations/query-creator-promotion-details-in-target-collaboration-202608.json) (POST /affiliate_seller/202608/target_collaborations/creator_promotion_details/query)：Query the creator commission rate, number of promotional video contents and number of live‑stream promotions for specified creator, specified invitation and specified product.
- [Query Target Collaboration Detail](operations/query-target-collaboration-detail-202508.json) (GET /affiliate_seller/202508/target_collaborations/{target_collaboration_id})：This API is used by Sellers to get target collaboration information.
- [Remove Creator From Open Collaboration](operations/remove-creator-from-open-collaboration-202508.json) (POST /affiliate_seller/202508/open_collaborations/{open_collaboration_id}/remove_creator)：This API is used to remove creators from open collaboration. Please note, due to current platform design, creators can still rejoin an open collaboration after removal. Partners/Sellers can call this API again to remove the creator again.
- [Remove Open Collaboration](operations/remove-open-collaboration-202409.json) (DELETE /affiliate_seller/202409/open_collaborations/products/{product_id})：Remove open collaboration for product. You can only remove open collaboration when `status==NORMAL`. When you call this API, the open collaborations will be terminated at `terminated_effective_time`, not immediately, to protect the interests of the creators. After `terminated_effective_time`, the open collaboration is officially terminated and can not be found in the response in [Search Open Collaboration].
- [Remove Target Collaboration](operations/remove-target-collaboration-202409.json) (DELETE /affiliate_seller/202409/target_collaborations/{target_collaboration_id})：This API is used by Seller to remove affiliate target collaboration.
- [Search Open Collaboration](operations/search-open-collaboration-202412.json) (POST /affiliate_seller/202412/open_collaborations/search)：Retrieve all open collaboration information from merchants, including commission rate, add to showcase and post content creator count.
- [Search Seller Affiliate Orders](operations/search-seller-affiliate-orders-202410.json) (POST /affiliate_seller/202410/orders/search)：This API allows the partner to retrieve a list of affiliate orders (orders which are affiliate-commission eligible) generated by a seller, returning the order ID and the product ID. Using this, the partner can track their affiliate-conversions on behalf of a seller, using the order ID.
- [Search Target Collaborations](operations/search-target-collaborations-202508.json) (POST /affiliate_seller/202508/target_collaborations/search)：This API is used by Seller to search for all existing target collaborations. Sellers can search based on filters such as Invitation name, Invitation ID, Product name, Product ID and Creator name.
- [Seller Get Sample Request Deeplink](operations/seller-get-sample-request-deeplink-202512.json) (GET /affiliate_seller/202512/sample_applications/deeplink)：Use this API to get a TikTok deeplink, use this deeplink to launch the TikTok app and land the user on the sample request page. * The seller can encode the deeplink into an QR code and send it to a creator via email.
- [Seller Review Sample Applications](operations/seller-review-sample-applications-202507.json) (POST /affiliate_seller/202507/sample_applications/{application_id}/review)：This API allows the seller to approve or reject the creator's sample application in an open collaboration. When rejecting an application, the seller must provide a specific reason. This API facilitates the management of sample applications by giving sellers the ability to review and update applications according to their criteria and requirements.
- [Seller Search Affiliate Open Collaboration Product](operations/seller-search-affiliate-open-collaboration-product-202405.json) (POST /affiliate_seller/202405/open_collaborations/products/search)：This API is used to search the information of products with open collaboration by category, commission rate, and keywords. It will return all products on the TikTok Shop Affiliate Product Marketplace that are in an open collaboration. Sellers can only search for open collaboration within the regions they are registered to sell in.
- [Seller Search Creator on Marketplace](operations/seller-search-creator-on-marketplace-202608.json) (POST /affiliate_seller/202608/marketplace_creators/search)：This API is used by Sellers to search for Creators in the Creator Marketplace. Sellers can search based on filters such as GMV, keywords, and Creator follower demographics. All the data returned is for the last 30 days.
- [Seller Search Sample Applications](operations/seller-search-sample-applications-202508.json) (POST /affiliate_seller/202508/sample_applications/search)：This API is provided for sellers to query sample applications based on various criteria such as products, creators, or application statuses. By using this API, sellers can retrieve detailed information about sample application records, including the creator's information and the specifics of each application.
- [Seller Search Sample Applications Fulfillments](operations/seller-search-sample-applications-fulfillments-202409.json) (POST /affiliate_seller/202409/sample_applications/{application_id}/fulfillments/search)：You, the seller, can use this API to get the fulfillment status of the specific sample application and whether the fulfillment resulted in orders. This allows Sellers to track the current progress or analyze the results of their sample distribution program.
- [Send IM Message](operations/send-im-message-202412.json) (POST /affiliate_seller/202412/conversations/{conversation_id}/messages)：The API for sending IM messages.
- [Update Conversation Status](operations/update-conversation-status-202608.json) (POST /affiliate_seller/202608/conversations/{conversation_id}/status)：Support starring or archiving a given conversation with creator.
- [Update Target Collaboration](operations/update-target-collaboration-202508.json) (PUT /affiliate_seller/202508/target_collaborations/{target_collaboration_id})：This API is used by Seller to update STANDARD target collaboration.
- [Upload Message Image](operations/upload-message-image-202511.json) (POST /affiliate_seller/202511/images/upload)：You must use this API to upload the image first, before sending an image as a message using [Send IM Messsage](https://partner.tiktokshop.com/docv2/page/send-im-message-202412)
- [Upload Message Image V2](operations/upload-message-image-v2-202608.json) (POST /affiliate_seller/202608/media/upload)：You must use this API to upload the image first, before sending an image as a message using [Send IM Messsage](https://partner.tiktokshop.com/docv2/page/send-im-message-202412)
