# API List

- [Cancel FBT MCF Order](operations/cancel-fbt-mcf-order-202601.json) (POST /fbt/202601/mcf_outbound_orders/cancel)：After an order is shipped via **FBT**, an **MCF Order** may be split into one or more `consign orders` for fulfillment. This API supports order cancellation at the level of individual `consign orders`, which can be done by providing the corresponding `mcf_order_id` and its associated `consign order` information. You can retrieve the information of `consign orders` associated with a `mcf_order_id` via the **Get FBF MCF Order Status** API.
- [Cancel Inbound Order](operations/cancel-inbound-order-202602.json) (POST /fbt/202602/inbound_orders/cancel)：This API is used to cancel an inbound order prior to warehouse arrival, preventing further processing and updating the order status. **If cancelling an inbound order that is part of a D2FC inbound plan, please make sure to cancel all orders under the inbound plan, otherwise non-compliance fees may be charged.**
- [Confirm Inbound Method](operations/confirm-inbound-method-202603.json) (POST /fbt/202603/confirm_inbound_method)：Finalize the selection of a specific warehouse placement option for a Fulfilled by TikTok (FBT) inbound plan.
- [Create FBT Goods](operations/create-fbt-goods-202607.json) (POST /fbt/202607/goods/create_goods)：Create FBT goods records, including SKU linkage, dimensions, hazmat details, shelf-life attributes, and return address information.
- [Create FBT MCF Order](operations/create-fbt-mcf-order-202607.json) (POST /fbt/202607/mcf_outbound_orders)：For orders created on other sales channels that require fulfillment via FBT, this API enables you to create corresponding orders (hereinafter referred to as MCF Orders). Once MCF Orders are successfully created, they will be automatically submitted to the FBT system for fulfillment.
- [Create or Update Inbound Plan](operations/create-or-update-inbound-plan-202602.json) (POST /fbt/202602/create_update_inbound_plan)：Initializes a new inbound plan or updates an existing one by defining goods, or carton configurations and dimensions.
- [Get FBT Inbound Order Details](operations/get-fbt-inbound-order-details-202602.json) (GET /fbt/202602/inbound_orders)：This API is used to retrieve the inbound order details including the planned inbound detail, actual inbound detail and inbound status, etc.
- [Get FBT MCF Order Status](operations/get-fbt-mcf-order-status-202601.json) (GET /fbt/202601/mcf_outbound_orders)：This API allows you to query the status of **MCF Orders**. When an order has not been shipped, the `consign_orders` field will contain no data; once the order has been shipped, the `consign_orders` field will display the consignment details of the order. If a single package cannot accommodate the entire order (due to carrier restrictions or packaging size limitations), the **FBT** system will split the order into multiple packages for fulfillment, in which case the `consign_orders` field will contain multiple entries corresponding to the respective packages.
- [Get FBT Merchant MCF Status](operations/get-fbt-merchant-mcf-status-202601.json) (GET /fbt/202601/merchants/mcf_status)：This API verifies whether a seller is registered as a Fulfillment by TikTok (FBT) merchant and participated in Multi Channel Fulfillment(MCF). If the seller is onboarded in FBT and enrolled in MCF, the API returns the true flag of MCF status.
- [Get FBT Merchant Onboarded Regions](operations/get-fbt-merchant-onboarded-regions-202409.json) (GET /fbt/202409/merchants/onboarded_regions)：This API verifies whether a seller is registered as a Fulfillment by TikTok (FBT) merchant. If the seller is onboarded, the API returns the regions where the merchant is authorized to operate under the FBT system.
- [Get FBT Warehouse List](operations/get-fbt-warehouse-list-202408.json) (GET /fbt/202408/warehouses)：This API is used to retrieve all Fulfilled by TikTok warehouse information including the warehouse name, warehouse address information, etc. The IDs of subscribed warehouses can be used to query inventory-related information.
- [Get Inbound Method Detail](operations/get-inbound-method-detail-202602.json) (POST /fbt/202602/inbound_method_detail)：Get detailed information regarding inbound plan placement options.
- [List Available Inbound Methods](operations/list-available-inbound-methods-202602.json) (POST /fbt/202602/list_available_inbound_method)：Retrieves valid inbound shipping methods and arrival time windows for a specific plan.
- [Print Inbound Order Labels](operations/print-inbound-order-labels-202602.json) (POST /fbt/202602/inbound_orders/label_print)：This API uses an **asynchronous Long-Running Operation (LRO)** pattern to generate label files. This pattern allows you to trigger a generation task and track its progress until completion. **Workflow Steps** 1. **Initiate** Send a request with `order_id` and the desired `print_items`. * **Response:** The API begins the print task and returns a `task_status` of `PROCESSING`. 2. **Poll** Send subsequent requests using the same fields from Step 1. If the print task is still processing, the API will continue to return `PROCESSING`. * **Frequency:** We recommend polling every 3–5 seconds. 3. **Complete** When the status returns `SUCCESS`, the response body will include a `download_url` for your generated ZIP file.
- [Query Goods Inventory For MCF](operations/query-goods-inventory-for-mcf-202601.json) (POST /fbt/202601/mcf/goods/inventory/search)：Search available inventory for MCF goods. Use this API to retrieve available quantities for the specified Fulfilled by TikTok goods IDs.
- [Search FBT Inventory](operations/search-fbt-inventory-202408.json) (POST /fbt/202408/inventory/search)：This API is used to retrieve detailed inventory information for goods and matched SKUs, including sellable inventory, reserved inventory, unsellable inventory, and in-transit inventory at the warehouse level.
- [Search FBT Inventory Record](operations/search-fbt-inventory-record-202410.json) (POST /fbt/202410/inventory_records/search)：This API is used to retrieve detailed inventory change records for goods at the warehouse level.
- [Search Goods Hazmat And Expiration Info](operations/search-goods-hazmat-and-expiration-info-202603.json) (POST /fbt/202603/goods/hazmat_and_expiration_info/search)：Search hazmat and expiration information for goods by TikTok Shop SKU IDs.
- [Search Goods Info](operations/search-goods-info-202607.json) (POST /fbt/202607/goods/search)：This API is used to retrieve a list of goods belonging to the merchant that meet the specified conditions. It returns detailed information about the goods, including their IDs, names, and other attributes, such as the goods-SKU relationship, dimensions, and weight as verified by the warehouse.
- [Ship Inbound Order](operations/ship-inbound-order-202603.json) (POST /fbt/202603/ship_inbound_order)：Finalizes the shipment details for a specific inbound order, including carton information and shipping methods.
- [Update FBT Goods Info](operations/update-fbt-goods-info-202607.json) (POST /fbt/202607/goods/update_goods_info)：Update FBT goods information, including goods name, image URL, dimensions, hazmat details, shelf-life attributes, and return address information.
- [Update Goods Sku Relation](operations/update-goods-sku-relation-202603.json) (POST /fbt/202603/goods/update_goods_sku_relation)：Bind or unbind TikTok Shop SKUs to FBT goods.
- [Update Inbound Order Tracking](operations/update-inbound-order-tracking-202602.json) (POST /fbt/202602/inbound_orders/tracking_update)：This API manages carton-level tracking information for inbound orders. It utilizes upsert logic to create new tracking records or overwrite existing entries as required. Only orders which are shipped but have not yet been marked as "Delivered" or "Received" yet can be updated, with a 5-time edit limit per carton.
