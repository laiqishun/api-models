# API List

- [Create Promotion Activity](operations/create-promotion-activity-202309.json) (POST /promotion/202309/activities)：Use this API to create a product discount activity or a flash deal activity. You cannot create a coupon activity with this API. To do that, you'll need to go to the seller center or the seller app. To update the products or SKUs included in the activity, use [Update Activity Product](https://partner.tiktokshop.com/docv2/page/650d32c42aaa3602b86ccb5c).
- [Deactivate Activity](operations/deactivate-activity-202309.json) (POST /promotion/202309/activities/{activity_id}/deactivate)：Deactivate an ongoing or upcoming activity.
- [Get Activity](operations/get-activity-202309.json) (GET /promotion/202309/activities/{activity_id})：Get the details of a product discount or flash deal promotion activity. Product information for `FIXED_PRICE`, `DIRECT_DISCOUNT` and `FLASHSALE` activity that ended more than 180 days will not be returned.For coupon activities, use [Get Coupon](6699dce0de15e502ed219e37).
- [Get Coupon](operations/get-coupon-202406.json) (GET /promotion/202406/coupons/{coupon_id})：Use this API to get the full details of a coupon matching the {coupon_id}.
- [Remove Promotion Activity Products](operations/remove-promotion-activity-products-202309.json) (DELETE /promotion/202309/activities/{activity_id}/products)：Use this API to remove products or SKUs from the existing product discount or flash sale promotion activity.
- [Republish Activity](operations/republish-activity-202607.json) (POST /promotion/202607/activities/{activity_id}/republish)：Use this API to republish a product discount activity or a flash deal activity that expired or was deactivated within the last 7 days. This API only supports FIXED_PRICE, FLASHSALE, and DIRECT_DISCOUNT activities. You must provide a new effective period by passing the new begin_time and end_time. Products and SKUs already associated with the activity do not need to be added again. After the activity is republished, you can edit the activity and modify its products or SKUs as usual. We recommend using this API instead of recreating the activity to reduce requests to the API for adding products.
- [Search Coupon List](operations/search-coupon-list-202406.json) (POST /promotion/202406/coupons/search)：Use this API to get a list of coupons, narrowed down further based on search parameters. The coupons are created in Seller Center or Seller App. For further details of the specific coupon, use `GET Coupon`.
- [Search Promotion Activities](operations/search-promotion-activities-202309.json) (POST /promotion/202309/activities/search)：Get a list of product discount or flash deal promotion activities. For coupon activities, use [Search Coupons](https://partner.tiktokshop.com/docv2/page/6699dcdf115ebe02f841e4cd).
- [Update Promotion Activity](operations/update-promotion-activity-202309.json) (PUT /promotion/202309/activities/{activity_id})：Change the title and the beginning and end time of the existing product discount or flash sale promotion activity.
- [Update Promotion Activity Products](operations/update-promotion-activity-products-202309.json) (PUT /promotion/202309/activities/{activity_id}/products)：Use this API to add the products or SKUs to the list of a product discount activity or a flash deal activity. You can also change the discounts on existing products or SKUs. To remove the products or SKUs from the list, use [Remove Activity Product](https://partner.tiktokshop.com/docv2/page/650acfd84a0bb702c072b4eb).
