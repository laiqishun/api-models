# API List

- [Approve Cancellation](operations/approve-cancellation-202309.json) (POST /return_refund/202309/cancellations/{cancel_id}/approve)：Use this API to approve a buyer-initiated cancellation request identified by cancel_id. Call this API only when the cancellation request is still waiting for seller action.
- [Approve Return](operations/approve-return-202309.json) (POST /return_refund/202309/returns/{return_id}/approve)：Use this API to approve a buyer's return request. The exact effect depends on the return type and return status. Before calling this API, make sure the return is still awaiting a seller action that matches the decision you are sending.
- [Calculate Refund](operations/calculate-refund-202602.json) (POST /return_refund/202602/refunds/calculate)：Use this API to estimate the refundable amount for a cancellation, refund, or return-and-refund request. The estimate depends on the selected request_type, reason_name, and targeted items. For return-and-refund scenarios, the estimate can also depend on the selected return shipping method.
- [Cancel Order](operations/cancel-order-202602.json) (POST /return_refund/202602/cancellations)：Use this API to cancel an order on behalf of a seller. In the US and UK markets, when an item is out of stock, partial cancellation on the single item level is supported by this API.
- [Create Return](operations/create-return-202602.json) (POST /return_refund/202602/returns)：Use this API to create a seller-initiated aftersales request for an order on behalf of the buyer. Supported request types are `REFUND` and `RETURN_AND_REFUND`. Before submitting the request, confirm that the order is eligible for the selected aftersales type and return method. After the request is created, use the relevant search, status, or review API to continue the aftersales workflow.
- [Get Aftersale Eligibility](operations/get-aftersale-eligibility-202602.json) (GET /return_refund/202602/orders/{order_id}/aftersale_eligibility)：Use this API to check eligible aftersale solutions for an order, including whether the seller or buyer can initiate a refund, return, or cancel a specific order.
- [Get Decision Eligibility](operations/get-decision-eligibility-202601.json) (GET /return_refund/202601/decision_eligibility)：Use this API to evaluate which seller decisions are currently allowed for the specified aftersales request. The API returns one result per requested decision, including whether the decision is currently eligible and any rejection reasons that are applicable for an eligible reject decision.
- [Get Reject Reasons](operations/get-reject-reasons-202309.json) (GET /return_refund/202309/reject_reasons)：Use this API to retrieve the seller reject-reason options currently applicable to the specified aftersales request. Use the returned name value as the reject reason key when calling the corresponding seller reject API.
- [Get Return Records](operations/get-return-records-202309.json) (GET /return_refund/202309/returns/{return_id}/records)：Use this API to retrieve the record entries for a specific return request. Each item in data.records represents an action or lifecycle event for the specified return_id.
- [Get Review Decision](operations/get-review-decision-202606.json) (GET /return_refund/202606/review_decision)：Description of [GET]/return_refund/:version/Get_Review_Decision
- [Reject Cancellation](operations/reject-cancellation-202309.json) (POST /return_refund/202309/cancellations/{cancel_id}/reject)：Use this API to reject a buyer's cancellation request for the specified cancel_id. Before calling this API, make sure the request is still in a state where seller rejection is currently allowed.
- [Reject Return](operations/reject-return-202606.json) (POST /return_refund/202606/returns/{return_id}/reject)：Use this API to reject a buyer's return or refund request. The valid decision depends on the current request type and status. Before calling this API, make sure the request is still awaiting the seller action that matches the decision you send.
- [Review Aftersales](operations/review-aftersales-202606.json) (POST /return_refund/202606/aftersales/review)：API used to review (approve, reject, or offer alternatives to) a buyer's return request.
- [Search Aftersales Request](operations/search-aftersales-request-202603.json) (POST /return_refund/202603/aftersales/search)：Used to search for aftersales request level data.
- [Search Cancellations](operations/search-cancellations-202602.json) (POST /return_refund/202602/cancellations/search)：Use this API to search and retrieve one or more order cancellations.
- [Search Return Merchandise Authorization](operations/search-return-merchandise-authorization-202604.json) (POST /return_refund/202604/rma/search)：Used to search for RMA request level data
- [Search Returns](operations/search-returns-202602.json) (POST /return_refund/202602/returns/search)：Use this API to search returns by return ID, order ID, buyer, return type, return status, arbitration status, or create/update time window. The response is paginated. To retrieve the next page, pass the previous `next_page_token` as `page_token` and keep all other filters and sorting unchanged.
- [Upload Shipping Document And Tracking Info](operations/upload-shipping-document-and-tracking-info-202405.json) (POST /return_refund/202405/returns/shipping_documents)：Use this API to upload return shipping documents, tracking numbers, and carriers for buyers.
