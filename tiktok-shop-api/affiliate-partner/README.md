# API List

- [Create Affiliate Partner Campaign](operations/create-affiliate-partner-campaign-202405.json) (POST /affiliate_partner/202405/campaigns)：This API offers the ability to create a campaign for targeted sellers/public sellers, including campaign period, campaign registration period and commission requirements. Note: The campaign will not be displayed to sellers after creation
- [Edit Affiliate Partner Campaign](operations/edit-affiliate-partner-campaign-202405.json) (POST /affiliate_partner/202405/campaigns/{campaign_id}/partial_edit)：This API offers the ability to edit an Affiliate Partner campaign. No editing after the campaign is closed.
- [Generate Affiliate Partner Campaign Product Link](operations/generate-affiliate-partner-campaign-product-link-202405.json) (POST /affiliate_partner/202405/campaigns/{campaign_id}/products/{product_id}/promotion_link/generate)：This API offers the ability to generate campaign product promotion links.
- [Get Affiliate Campaign Creator Fulfillment Status Info](operations/get-affiliate-campaign-creator-fulfillment-status-info-202508.json) (GET /affiliate_partner/202508/campaigns/{campaign_id}/products/{product_id}/performance)：This API offers the ability to get the product fulfillment status for creators who added partner campaign products to their showcase
- [Get Affiliate Campaign Creator Fulfillment Status List](operations/get-affiliate-campaign-creator-fulfillment-status-list-202501.json) (GET /affiliate_partner/202501/campaigns/{campaign_id}/products/performance)：This API offers the ability to get the product of the campaign fulfillment status for creators who added partner campaign products to their showcase. For details of a specified product involved in an affiliated campaign, use Get Affiliate Campaign Creator Fulfillment Status Info gateway.
- [Get Affiliate Campaign Creator Product Content Statistics](operations/get-affiliate-campaign-creator-product-content-statistics-202508.json) (GET /affiliate_partner/202508/campaigns/{campaign_id}/products/{product_id}/creator/{creator_temp_id}/content/statistics)：Get statistics on creator's marketing video content
- [Get Affiliate Campaign Creator Product Sample Status](operations/get-affiliate-campaign-creator-product-sample-status-202508.json) (GET /affiliate_partner/202508/campaigns/{campaign_id}/products/{product_id}/creator/{creator_temp_id}/content/statistics/sample/status)：Get progress on creator's sample status
- [Get Affiliate Partner Campaign Detail](operations/get-affiliate-partner-campaign-detail-202405.json) (GET /affiliate_partner/202405/campaigns/{campaign_id})：This API offers the ability to get affiliate campaign details.
- [Get Affiliate Partner Campaign List](operations/get-affiliate-partner-campaign-list-202405.json) (GET /affiliate_partner/202405/campaigns)：This API offers the ability to list campaigns created by the Affiliate Partner.
- [Get Affiliate Partner Campaign Product List](operations/get-affiliate-partner-campaign-product-list-202405.json) (GET /affiliate_partner/202405/campaigns/{campaign_id}/products)：This API offers the ability to list products submitted by sellers in an Affiliate Partner campaign.
- [Partner Generate Multi Affiliate Campaign Product Link](operations/partner-generate-multi-affiliate-campaign-product-link-202505.json) (POST /affiliate_partner/202505/campaigns/{campaign_id}/products/promotion_links/generate_batch)：This API offers the ability to generate promotion links for multiple products in a campaign.
- [Publish Affiliate Partner Campaign](operations/publish-affiliate-partner-campaign-202405.json) (POST /affiliate_partner/202405/campaigns/{campaign_id}/publish)：This API offers the ability to publish an Affiliate Partner campaign. The campaign will be displayed to sellers after publishing.
- [Review Affiliate Partner Campaign Product](operations/review-affiliate-partner-campaign-product-202405.json) (POST /affiliate_partner/202405/campaigns/{campaign_id}/products/{product_id}/review)：This API offers the ability for the TikTok Affiliate Partner to review the products submitted by the sellers. This API offers the ability for the TikTok Affiliate Partner to review the products submitted by the sellers.
- [Search CAP Affiliate Orders](operations/search-cap-affiliate-orders-202603.json) (POST /affiliate_partner/202603/cap_order/search)：Search the list of affiliate orders of the specified date range from a MCN or known as CAP - Creator Agency partner
- [Search Tap Affiliate Orders](operations/search-tap-affiliate-orders-202603.json) (POST /affiliate_partner/202603/orders/search)：TAP can use this API to retrieve a list of affiliate orders and track the affiliate conversions.
