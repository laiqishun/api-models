# API List

- [Create Conversation](operations/create-conversation-202309.json) (POST /customer_service/202309/conversations)：Use this API to create a conversation with the specified buyer, on behalf of a shop. When there's no prior conversation, calling this API creates a new conversation; when there's a prior conversation, no matter whether it's active, finished, or closed, calling this API reopens the conversation and returns the same conversation ID as the prior one.
- [End Session](operations/end-session-202605.json) (POST /customer_service/202605/conversations/{conversation_id}/sessions/{session_id}/end)：Use this API to end an active customer service session assigned to an agent.
- [Get Agent Settings](operations/get-agent-settings-202309.json) (GET /customer_service/202309/agents/settings)：This API is used to get agent settings. This API allows the agent to see whether the agent can accept chats from buyers. This API is a read-only endpoint. There will be no side effects, and can be retried safely. Note: 1. The current API version can only get settings on behalf of the shop, or the owner account holder on Seller Center. The owner in this case is acting as the customer service agent. In the future, we plan to make this API available to subaccount holders (who has customer service role) in Seller Center. 2. This API is to allow the agent to get his/her own setting. See more information in API overview
- [Get Conversation](operations/get-conversation-202601.json) (GET /customer_service/202601/conversations/{conversation_id})：Use this API to retrieve information about a conversation by ID.
- [Get Conversation Messages](operations/get-conversation-messages-202309.json) (GET /customer_service/202309/conversations/{conversation_id}/messages)：Use this API to get all messages in a conversation between a buyer and a shop. Calling this API does not mark the messages as read. You are suggested to call [Read Message](650a59f7c16ffe02b8e8db3f) to mark the messages read.
- [Get Conversations](operations/get-conversations-202309.json) (GET /customer_service/202309/conversations)：Use this API to retrieve a shop's conversations with buyers.
- [Get Customer Service Performance](operations/get-customer-service-performance-202407.json) (GET /customer_service/202407/performance)：Get the average customer service performance of a shop for a selected time period
- [Read Message](operations/read-message-202309.json) (POST /customer_service/202309/conversations/{conversation_id}/messages/read)：Use this API to mark all messages sent by the buyer as read. You are suggested to call this API before replying to their messages.
- [Search Sessions](operations/search-sessions-202602.json) (POST /customer_service/202602/sessions/search)：Description of [POST]/customer_service/:version/sessions
- [Send Message](operations/send-message-202606.json) (POST /customer_service/202606/conversations/{conversation_id}/messages)：Use this API to send a message to the buyer in a conversation.
- [Update Agent Settings](operations/update-agent-settings-202309.json) (PUT /customer_service/202309/agents/settings)：Use this API to update agent status on behalf of the agent. Agents can set whether they can accept auto assigned chats. Before using API, we recommend setting can_accept_chat to true, in order to accept chats. Note: 1. The current API version can only update settings on behalf of the shop, or the owner account holder on Seller Center. The owner in this case is acting as the customer service agent. In the future, we plan to make this API available to subaccount holders (who has customer service role) in Seller Center. 2. This API is to allow the agent to update their own setting. See more information in API overview
- [Upload Buyer Messages Image](operations/upload-buyer-messages-image-202309.json) (POST /customer_service/202309/images/upload)：You must use this API to upload the image first, before sending an image as a message using [Send Message](650a58bbbace3e02b7556286).
