# API List

- [Delete Shop Webhook](operations/delete-shop-webhook-202309.json) (DELETE /event/202309/webhooks)：Deletes the shop's webhook URL for a specific event topic. Regardless of whether webhook is configured or not, the result will return success.
- [Get Shop Webhooks](operations/get-shop-webhooks-202309.json) (GET /event/202309/webhooks)：Retrieves a shop's webhooks and the corresponding webhook URLs.
- [Update Shop Webhook](operations/update-shop-webhook-202309.json) (PUT /event/202309/webhooks)：Updates the shop's webhook URL for a specific event topic.
